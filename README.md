# Fama Mennou – Frontend

A modern freelance marketplace platform connecting clients and freelancers in Tunisia.

🌐 Live Demo: https://famamennou.tn

## Overview

Fama Mennou is a full-stack marketplace built to connect clients and freelancers through a modern, secure, and scalable platform.

This repository contains the frontend application.

## Features

- Authentication and authorization
- Freelancer marketplace
- Client project publishing
- Freelancer and client dashboards
- Real-time messaging
- Notifications system
- Online courses
- Project management
- Multi-language support (French, English, Arabic)
- Responsive design
- Admin panel
- Real-time collaboration

## Tech Stack

- React
- Tailwind CSS
- React Router
- Socket.io
- Framer Motion
- i18next
- Playwright
- GitHub Actions
- Sentry
- Vercel
